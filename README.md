# Forte — Front-end do SaaS para pequenos negócios

## Conceito

O Forte é apresentado como uma plataforma SaaS de apoio ao pequeno empreendedor.

Várias empresas podem utilizar a mesma plataforma por assinatura mensal. Cada negócio possui seus próprios dados e um ambiente personalizado, enquanto o Forte transforma esses dados em:

- visão financeira;
- estatísticas;
- análise de estoque;
- histórico de vendas;
- relacionamento com clientes;
- oportunidades de crescimento;
- vitrine digital.

A ideia central do produto é:

**Dados → Análise → Informação → Decisão**

## Estrutura

```text
forte_saas_frontend/
├── index.html
├── css/
│   └── style.css
├── js/
│   └── app.js
└── README.md
```

## Como executar

Não existe backend neste protótipo.

1. Extraia a pasta.
2. Abra `index.html` em um navegador.
3. Navegue pelo menu.

O protótipo usa `localStorage`, então cadastros feitos durante a demonstração continuam disponíveis no mesmo navegador.

## Funcionalidades demonstráveis

- troca de empresa no ambiente;
- dashboard com indicadores;
- estatísticas e análises;
- gráficos;
- insights;
- financeiro;
- estoque com pesquisa e filtros;
- vendas;
- clientes;
- oportunidades;
- vitrine digital;
- modal para novas vendas, despesas, produtos e clientes;
- central de notificações;
- seletor de período;
- exportação simples de relatório;
- responsividade para celular.

## Próxima evolução para MVP

Para sair do protótipo e virar produto real:

- autenticação;
- banco de dados multiempresa;
- isolamento de dados por empresa;
- planos e assinatura mensal;
- backend/API;
- permissões de usuários;
- persistência real de vendas, estoque e financeiro;
- cálculo de métricas no servidor;
- relatórios PDF/CSV;
- integração da vitrine com pedidos;
- regras tributárias e lembretes validados por profissional/serviço especializado.
